ImageViewer.js

一个现代化的、轻量级的、可自定义的图片预览 Web Component

Web Components 零依赖 TypeScript MIT License

核心特性

🔍

智能缩放

鼠标滚轮平滑缩放，支持自定义缩放范围

🖱️

拖拽平移

缩放后可拖拽查看图片细节，操作流畅自然

🔄

图片旋转

支持90度增量旋转，完美适配各种图片方向

📥

一键下载

快速下载原图，支持自定义文件名

使用说明

  • 点击图片 - 打开全屏预览模式
  • 鼠标滚轮 - 缩放图片（支持自定义范围）
  • 拖拽图片 - 在缩放状态下平移查看
  • 旋转按钮 - 90度旋转图片
  • 下载按钮 - 保存原图到本地
  • 导航按钮 - 在多张图片间切换
  • ESC 键 - 快速关闭预览
  • 左右箭头 - 键盘切换图片

点击下方图片体验预览功能

提示：部分图片使用了高分辨率版本，预览时会加载更清晰的图片

快速集成

基础用法（自动初始化）

<!-- 引入组件 -->
<script src="image-viewer.js"></script>

<!-- 你的图片 -->
<img src="image1.jpg" alt="图片描述">
<img src="image2.jpg" alt="另一张图片">

高级配置（使用 data 属性）

<script src="image-viewer.js" 
        id="gd-image-viewer"
        data-target-selector=".previewable"
        data-max-scale="8"
        data-min-scale="0.3"
        data-allow-rotate="true"
        data-allow-download="true">
</script>

<!-- 只有带 previewable 类的图片可预览 -->
<img src="image1.jpg" class="previewable" alt="图片1">
<img src="image2.jpg" class="previewable" alt="图片2">
<img src="image3.jpg" alt="这张图片不会被预览">
