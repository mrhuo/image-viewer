# ImageViewer.js - 现代化图片预览组件

## 🚀 项目概述

ImageViewer.js 是一个**现代化、轻量级、零依赖**的图片预览 Web Component。它提供了完整的图片预览功能，包括缩放、拖拽、旋转、下载等，只需要引入一个 JavaScript 文件即可快速集成到任何项目中。

## ✨ 核心特性

### 🎯 零依赖设计
- **纯原生 JavaScript**：不依赖任何第三方库
- **Web Components 标准**：使用现代浏览器原生支持的 Web Components 技术
- **轻量级**：压缩后仅约 10KB，加载速度快

### 🖼️ 丰富的预览功能
- **智能缩放**：鼠标滚轮平滑缩放，支持自定义缩放范围
- **拖拽平移**：缩放后可拖拽查看图片细节
- **图片旋转**：支持 90 度增量旋转
- **一键下载**：快速下载原图，支持自定义文件名
- **多图导航**：在多张图片间无缝切换
- **键盘支持**：ESC 关闭，左右箭头切换图片

### ⚡ 快速集成
- **一行代码集成**：只需引入一个 JS 文件
- **自动初始化**：DOM 加载完成后自动初始化
- **灵活配置**：支持通过 data 属性或 JavaScript 配置

## 🛠️ 快速开始

### 基础用法
```html
<!-- 引入组件 -->
<script src="image-viewer.js"></script>

<!-- 你的图片 -->
<img src="image1.jpg" alt="图片描述">
<img src="image2.jpg" alt="另一张图片">
```

### 高级配置
```html
<script src="image-viewer.js" 
        id="gd-image-viewer"
        data-target-selector=".previewable"
        data-max-scale="8"
        data-min-scale="0.3"
        data-allow-rotate="true"
        data-allow-download="true">
</script>

<!-- 只有带 previewable 类的图片可预览 -->
<img src="image1.jpg" class="previewable" alt="图片1">
<img src="image2.jpg" class="previewable" alt="图片2">
```

## 📋 配置选项

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `targetSelector` | string | `'img'` | 目标图片选择器 |
| `maxScale` | number | `5` | 最大缩放比例 |
| `minScale` | number | `0.5` | 最小缩放比例 |
| `allowRotate` | boolean | `true` | 是否允许旋转 |
| `allowDownload` | boolean | `true` | 是否允许下载 |

## 🎨 使用体验

### 操作方式
- **点击图片**：打开全屏预览模式
- **鼠标滚轮**：缩放图片
- **拖拽图片**：在缩放状态下平移查看
- **旋转按钮**：90 度旋转图片
- **下载按钮**：保存原图到本地
- **导航按钮**：在多张图片间切换
- **ESC 键**：快速关闭预览
- **左右箭头**：键盘切换图片

### 用户体验
- **流畅动画**：所有操作都有平滑的过渡动画
- **响应式设计**：完美适配各种屏幕尺寸
- **无障碍支持**：支持键盘操作和屏幕阅读器
- **高性能**：使用 Shadow DOM 实现样式隔离

## 🔧 技术架构

### 核心技术
- **Web Components**：使用 Custom Elements 和 Shadow DOM
- **ES6+**：现代 JavaScript 语法
- **MutationObserver**：动态监听 DOM 变化
- **事件委托**：高效的事件处理机制

### 架构优势
- **模块化设计**：每个功能独立封装，易于维护
- **样式隔离**：Shadow DOM 确保样式不会影响页面其他部分
- **内存管理**：自动清理事件监听器，避免内存泄漏
- **错误处理**：完善的错误处理机制
